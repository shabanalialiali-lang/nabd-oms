# نبض خدمات — تطبيق جوال للصيانة العامة

تطبيق جوال (أندرويد + آيفون) يربط العملاء بالفنيين في كل مهن الصيانة:
كهرباء، سباكة، تكييف وتبريد، إلكترونيات، أجهزة منزلية، نجارة، دهانات، بلاط، جبس، حدادة، ألمنيوم،
أقفال، كاميرات وشبكات، دش، خزانات ومضخات، سخانات، عزل، طاقة شمسية، مكافحة حشرات، تنظيف، حدائق، نقل أثاث، وأعمال متنوعة.

مبني بـ **Expo (React Native)** ويستخدم **نفس قاعدة بيانات Supabase** لنظام نبض.

## كيف يعمل التطبيق

| العميل 🏠 | الفني 🧰 |
|---|---|
| يختار الخدمة من شبكة المهن | يحدد المهن التي يعمل بها ومدينته |
| يكتب المشكلة، العنوان، الجوال، الموعد، ويحدد إن كان طارئًا | تظهر له الطلبات الجديدة في مهنه فقط (الطارئ أولًا) |
| يتابع حالة الطلب: بانتظار فني ← تم القبول ← جارٍ التنفيذ ← مكتمل | يقبل الطلب (أول فني يقبل يأخذه) ثم يرى عنوان وجوال العميل |
| يتصل بالفني مباشرة من التطبيق | يبدأ التنفيذ، ثم ينهي العمل ويسجل التكلفة |
| يلغي الطلب قبل بدء التنفيذ، ويقيّم الفني بعد الإنجاز | يرى أعماله الجارية والمنجزة، تقييمه، ودخله |

**حماية البيانات:** عنوان العميل ورقم جواله لا يظهران لأي فني إلا بعد قبوله الطلب،
وكل تغيير في حالة الطلب يمر عبر دوال في قاعدة البيانات تتحقق من الصلاحية (لا يستطيع فني إنهاء طلب ليس له، ولا عميل تعديل السعر).

## الخطوة 1: تجهيز قاعدة البيانات (مرة واحدة)

1. افتح مشروعك في https://supabase.com ← **SQL Editor** ← **New query**.
2. إذا لم تشغّل `supabase/schema.sql` من قبل، شغّله أولًا.
3. انسخ محتوى الملف `supabase/services_schema.sql` بالكامل، الصقه، واضغط **Run**.
   (الملف آمن لإعادة التشغيل، ولا يمس بلاغات نظام المستشفى الحالية.)

## الخطوة 2: تجربة التطبيق على جوالك (بدون متجر)

على جهاز الكمبيوتر (يحتاج Node.js 20 أو أحدث):

```
cd mobile
npm install
npx expo start
```

- حمّل تطبيق **Expo Go** على جوالك من Google Play أو App Store.
- امسح رمز QR الذي يظهر في الشاشة (الكمبيوتر والجوال على نفس شبكة الواي فاي).
- في أول تشغيل سيعيد التطبيق تحميل نفسه مرة واحدة لتفعيل الاتجاه العربي (من اليمين لليسار).

للتجربة على المتصفح: `npx expo start --web`

> مفاتيح Supabase موجودة في `mobile/.env`. لو غيّرت مشروع Supabase عدّل القيمتين هناك.

## نسخة ويب برابط (تنفتح من متصفح الجوال)

1. في https://vercel.com اضغط **Add New → Project** واختر مستودع `nabd-oms`.
2. في **Root Directory** اختر `mobile` (الإعدادات الباقية تُقرأ من `mobile/vercel.json`).
3. اضغط **Deploy** — ستحصل على رابط مثل `https://nabd-services.vercel.app`.
4. من الجوال: افتح الرابط ← «إضافة إلى الشاشة الرئيسية» ليظهر كأيقونة تطبيق.

> يمكن أيضًا استخدام مشروع Vercel المكرر `nabd-oms-986x` بدل إنشاء مشروع جديد: غيّر فيه Root Directory إلى `mobile`.

## الخطوة 3: النشر على المتاجر (Google Play / App Store)

يتم البناء على سحابة Expo بدون الحاجة لـ Android Studio أو Xcode:

```
npm install -g eas-cli
eas login
eas build:configure
eas build --platform android     # ملف .aab لـ Google Play
eas build --platform ios         # يحتاج حساب Apple Developer
eas submit --platform android
```

- حساب Google Play Developer: رسوم لمرة واحدة (25$).
- حساب Apple Developer: اشتراك سنوي (99$).
- غيّر `android.package` و `ios.bundleIdentifier` في `app.json` لاسم خاص بشركتك قبل أول نشر.

## هيكل المجلد

```
mobile/
  app.json                  اسم التطبيق والأيقونات وإعدادات النشر
  .env                      مفاتيح Supabase
  src/app/                  الشاشات (كل ملف = شاشة)
    login.js, signup.js       الدخول وإنشاء حساب (عميل / فني)
    customer/                 تبويبات العميل: الخدمات، طلباتي، حسابي
    tech/                     تبويبات الفني: طلبات متاحة، أعمالي، حسابي
    new-order.js              نموذج طلب خدمة
    order/[id].js             تفاصيل الطلب والإجراءات حسب الدور
  src/components/           مكونات الواجهة المشتركة
  src/constants/categories.js  قائمة المهن — أضف مهنة جديدة بسطر واحد
  src/lib/                  الاتصال بـ Supabase وتسجيل الدخول
```

## أفكار للمرحلة القادمة

- إرفاق صور للعطل (Supabase Storage).
- إشعارات فورية للفني عند وصول طلب جديد (expo-notifications).
- تحديد الموقع على الخريطة وحساب المسافة لأقرب فني.
- عروض أسعار من أكثر من فني بدل «أول من يقبل».
- الدفع الإلكتروني وعمولة للمنصة.
- لوحة إدارة على الويب (داخل نظام نبض) لمتابعة الطلبات والفنيين وتوثيقهم.
